# 📦 Product Inventory & Analytics Dashboard

**A beginner-friendly inventory management project built using HTML, CSS, and JavaScript.**

The **Product Inventory & Analytics Dashboard** helps users manage product details, view inventory statistics, search products, and filter products by category.

This project is part of a JavaScript assignment designed to practice fundamental programming concepts such as variables, conditional statements, loops, functions, arrays, objects, and array methods.

---

## ✨ Features

- **Add Products:** Enter product name, price, quantity, and category.
- **Inventory Summary:** Calculate total products, total quantity, and total inventory value.
- **Product List:** Display product details in a table.
- **Search Products:** Find products by name.
- **Category Filter:** Filter products by category.
- **Low Stock Alert:** Identify products with a quantity of 5 or less.
- **Responsive Layout:** A simple interface with a light bluish-green theme.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Enter product details in the form.
5. Click **Add Product** to add a product to the inventory.
6. Use the search field and category filter to find products.
